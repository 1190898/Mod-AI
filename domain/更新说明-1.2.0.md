# 领域展开 1.2.0

## 开放领域

管理员执行 `/domainexpansion grantopen 玩家名`，授予专门的开放权限与普通领域权限，首次给予**普通发放量＋64（默认 320 个）的“领域基岩*”**和一份开放平台蓝图。放置领域基岩*、建造蓝图、用锤收纳和展开开放领域，都要求**当前经验等级至少 75 级**；等级不被消耗，创造模式也需达到该等级。

底面使用同一高度、相连的领域基岩*，长宽至少各 3 格，至少 9 个方块。可搭矩形或其他连通底面；最多保存平台上方的 15 层空间，保存高度还受开放边长上限影响。平台需要位于世界建造高度允许的位置，并遵守开放领域尺寸、体积与填充数量限制。开放蓝图生成 **9×9** 底面，生存模式消耗 **81 个“领域基岩*”**，不建墙和顶。

用原有领域锤收纳，再携带自己的核心展开。开放平台仍保存在专属领域维度，内部没有墙和顶：其他参与者走出平台范围会返回原世界；主人走出则解除领域。外部显示可攻击的薄平台代理，不形成封闭大盒子的碰撞。外部平台击破后按原有规则解除并进入加倍冷却。

原有核心、缩放镜、赋能台、织纹台、收纳／还原、敌友规则、领域 Buff、必中和领域对抗适用。开放基岩与平台蓝图支持自绘、颜色和透明度，掉落与模板保存外观。每名玩家仍保存一个建筑领域，可以是封闭或开放领域。

| 指令 | 用途 |
|---|---|
| `/domainexpansion grantopen 玩家名` | 授予开放权限并首次发放材料与蓝图 |
| `/domainexpansion revokeopen 玩家名` | 撤销开放权限，解除活跃开放领域或取消其领域挑战 |
| `/domainexpansion openbedrock 玩家名 256` | 补发领域基岩* |
| `/domain expand`、`/domain dismiss`、`/domain scale set 2` | 原有展开、解除和缩放命令 |
| `/domainexpansion config duration 300` | 建筑领域持续时间，开放与封闭共用 |
| `/domainexpansion config cooldown 30` | 建筑领域普通冷却，开放与封闭共用 |
| `/domainexpansion config radius 12` | 展开时吸纳生物半径，开放与封闭共用 |

## 简易领域

管理员执行 `/domainsimple grant 玩家名`，授予权限并首次发放**简易领域圆环**。手持淡蓝色圆环右键一次，术式持续至计时结束，无需一直按住或继续手持；再次使用不会延长持续时间。圆环跟随玩家脚底移动。

默认持续 **30 秒**、结束后冷却 **20 秒**、半径 **3 格**。圆环内的生物承受普通伤害时减少 **25%**；处于敌方开放／封闭领域中时，圆环内暂停该领域的必中转换、空挥必中辅助、投射物追踪目标选择和领域 Buff。已有的短时领域效果会移除，普通药水效果保留；已发生的瞬时治疗／伤害不会倒退。

圆环会与所在的敌方建筑领域发起局部对抗，复用顶部红蓝进度条。强度随生命、饥饿和经验变化；简易领域强度按同资源建筑领域的 85% 计算。**简易领域获胜后继续局部压制，原领域仍存在**；失败时圆环解除并进入冷却。进行中的局部对抗不接受第三个建筑领域插入。多组远处领域仍独立运行。

圆环只影响自身覆盖范围。离开圆环的生物重新遵循原领域规则。半径随领域中的实体比例变化，例如内部实体缩为一半时圆环半径也为配置值的一半。

```text
/domainsimple grant 玩家名
/domainsimple revoke 玩家名
/domainsimple config radius 4
/domainsimple config duration 30
/domainsimple config cooldown 20
/domainsimple info
/domainsimple item
/domainsimple use
/domainsimple dismiss
```

修改与授予命令需管理员权限等级 2；查看、补领自身物品、使用和解除由玩家执行，使用与补领仍校验专门授权。半径范围 **0.5～16 格**，持续时间 **1～3600 秒**，冷却 **0～3600 秒**。

## 延展领域

管理员执行 `/domainextension grant 玩家名`，授予权限并首次发放**延展领域气符**。右键一次后，全身显示持续涌动的淡蓝气流，默认持续 **15 秒**，结束后冷却 **20 秒**。

攻击通过标准伤害事件时转为原有无攻击者的必中伤害，绕过常规防御和伤害间隔；同时清除这次攻击的玩家／生物伤害归属，不采用建筑领域的玩家战利品归属设置。术式本身不授予力量、抗性或其他领域 Buff，不收纳场地，不形成外壳。

延展提供当前近战距离内的前方空挥辅助，投射物在前方目标范围内获得追踪。投射物仍遵循 Minecraft 的碰撞路径。绕过标准伤害事件、没有可识别攻击者的模组攻击，需要对应模组的专项适配。

```text
/domainextension grant 玩家名
/domainextension revoke 玩家名
/domainextension config duration 15
/domainextension config cooldown 20
/domainextension info
/domainextension item
/domainextension use
/domainextension dismiss
```

延展只有持续时间与冷却设置，**不提供半径设置**。持续时间 **1～3600 秒**，冷却 **0～3600 秒**。简易与延展不能同时维持，切换时旧术式结束并进入各自冷却。

## 保存、显示与边界

可用 `/domain edit false` 防止内部装修误挖和误放，或分别设置破坏／放置权限。开关对活跃的开放和封闭领域立即生效，保存规则保持一致。管理员命令见 [内部修改开关](更新说明-1.2.0-内部修改开关.md)。

开放与封闭领域统一保留内部方块、库存与装饰改动。外部代理被击破后会在下一次展开时重新生成，内部继续使用最新保存状态。两类对照回归与解释见 [保存行为核查](保存行为核查-20261011.md)。

术式设置按世界保存，权限和冷却随玩家保存并在死亡克隆时保留。持续时间用于下次激活，冷却用于下次结束；简易半径可实时调整。死亡、离线、撤销对应授权或服务器关闭会结束术式并记录冷却；撤销另一种术式的授权不会打断当前术式。跨维度时气场跟随玩家重新生成。物品不会因激活消耗。

右上方 HUD 显示术式持续／冷却，沿用 Alt+H 隐藏与原有位置配置。圆环与气流由同步的气场实体绘制；双面圆环可从上下两侧看见，气场按客户端玩家的位置插值跟随，不给世界放置临时方块。世界中的旧建筑领域默认仍识别为封闭领域，原有核心与绘图数据保留。
