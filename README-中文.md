# 领域展开 1.0.1 使用说明

适用版本：Minecraft 1.20.1、Forge 47.3.0、Java 17。客户端与服务器均需安装同一版本 JAR，无需额外缩放模组。

## 本次补充功能

**HUD** 默认位于顶部偏右（屏幕横向 78% 的位置，距顶部 12 个 GUI 像素）。按 **Alt+H** 显示／隐藏，重启后记住选择。也可执行 `/domainhud show`、`/domainhud hide`、`/domainhud toggle`。位置可用 `/domainhud position 0.78 12` 调整，横向取值 0～1。配置位于 `config/domain_expansion-client.toml`。

**预制蓝图**：球形、封闭半球、方盒、尖顶房屋四种。首次获权时自动收到蓝图，已有权限的玩家用 `/domain blueprints` 补领；管理员可用 `/domainexpansion blueprints 玩家名` 发放。蓝图可以重复使用，生存模式建造时消耗背包中对应数量的领域基岩，数量显示在物品提示中，创造模式免费。

| 外壳 | 原始尺寸 | 所需领域基岩 |
|---|---|---|
| 球形 | 11 × 11 × 11 | 222 |
| 封闭半球 | 13 × 7 × 13 | 274 |
| 方盒 | 9 × 9 × 9 | 386 |
| 尖顶房屋 | 11 × 12 × 13 | 556 |

用蓝图右键空地的地面，生成以点击位置为底部中心的封闭基岩外壳。内部方块不会被清空或填充，可以自行装饰，再用领域锤收纳。外壳不能覆盖已有方块、方块实体或实体身体，不能紧邻已有领域基岩；被保护规则阻止时撤销放置且不扣材料。半球包含封闭的圆形底面，房屋的尖顶也由基岩封住。

蓝图合成：纸 + 领域基岩得到方盒蓝图；方盒蓝图 + 黏液球／玻璃／木板分别得到球形／半球／房屋蓝图。收纳并展开后的外部代理仍沿用原有长方体渲染。

**领域赋能台**：合成摆法为第一行居中放书，第二行“黑曜石、领域基岩、黑曜石”，第三行三个黑曜石。放置后右键打开管理界面，背包内须携带自己的有效领域核心。选择主人、友方、敌方或中立，搜索效果名称或资源 ID，点击启用／停用，使用 −／+ 调整等级（显示为 1～10 级），也可清空当前类别。配置保存到自己的领域；其他人使用同一台子只管理自己的领域。支持当前整合包已注册的模组效果。

**领域锤** 改为宽锤头与短木柄的黑曜石紫纹像素造型，贴图为带透明背景的 64×64 PNG。

本次内部通信协议有更新。尽管模组版本仍为 1.0.1，服务器和所有客户端需要同时替换成这次的 JAR，不能与之前的同号 JAR 混用。

## 基本流程

1. 管理员执行 `/domainexpansion grant 玩家名`，授予权限并给予 256 个领域基岩。
2. 用领域基岩搭建六个方向均封闭的外壳，不能留门洞。默认各边不超过 32 格，包围盒体积不超过 65536 格。内部可以放普通方块、箱子、物品展示框、画和盔甲架。
3. 达到 50 级后自动获得领域锤和缩放镜。管理员也可执行 `/domainexpansion tools 玩家名` 提前发放。
4. 用领域锤右键外壳上的基岩，将建筑移入专属维度，并获得绑定你的领域核心。每人只能保存一个领域。
5. 携带有效核心，右键使用核心、按 **G**，或执行 `/domain expand` 展开。默认吸入半径为 12 格，包括领域主人；消耗 6 点饥饿值。原地的建筑、植物和掉落物不会被吸入。
6. 右键缩放镜放大领域，潜行时右键缩小。背包携带缩放镜时可按 **]** 放大、**[** 缩小。支持展开前预设比例和展开后调整。
7. 再次使用核心、按 **G**，或执行 `/domain dismiss` 主动解除。默认 180 秒自动解除；主人死亡、离线或离开领域也会解除。外部外壳被打至零生命值时领域崩溃。

默认解除后冷却 30 秒，外壳被击破时冷却 60 秒。生物和玩家返回原维度、原位置附近的无碰撞空间；内部掉落物和经验会带回外部。

创造模式主人不消耗饥饿值，默认不吸入其他创造玩家。旁观者、末影龙、带 `forge:bosses` 标签的 Boss 和装饰盔甲架不作为吸入对象。

## 缩放

| 领域比例 | 外部外壳 | 内部生物与掉落物 |
|---|---|---|
| 0.5 | 原尺寸的一半 | 原尺寸的两倍 |
| 1 | 原尺寸 | 原尺寸 |
| 2 | 原尺寸的两倍 | 原尺寸的一半 |
| 4 | 原尺寸的四倍 | 原尺寸的四分之一 |

内部建筑按原始方块尺寸存储，实体反向缩放产生空间变大或变小的效果。默认档位为 0.5、0.75、1、1.5、2、3、4。`/domain scale set 数值` 可设置配置允许范围内的中间比例。

如果某个生物在当前比例下放不进房间，展开或缩放会被拒绝。请增加内部净空，或提高领域比例，让内部实体变小。

## 修改和保存

领域内的方块改动、箱子库存、装饰实体均会保留。**其他进入者造成的改动同样保留**。关闭领域不会补回旧库存或复活被破坏的装饰。领域基岩无法从内部挖掘、爆破或被活塞推动。

修改外壳：先解除，再潜行时用核心右键外部方块，将建筑以原始大小还原。目标区域必须空闲，不能覆盖方块实体或超出世界边界。修改完成后用领域锤重新收纳。

## 敌友和 Buff

默认主人获得力量 I、抗性提升 I；友方获得生命恢复 I；敌方获得缓慢 I、虚弱 I。未指定的生物默认视为敌方，自身驯养的宠物默认视为友方。

```text
/domain ally add player 玩家名
/domain enemy add mob minecraft:zombie
/domain ally add group passive
/domain enemy add group hostile
/domain ally add entity 生物UUID
/domain default neutral
/domain effect owner add minecraft:strength 1
/domain effect enemy add minecraft:slowness 2
/domain effect ally remove minecraft:regeneration
/domain effects
```

`entity` 标记某一只具体生物，也可使用实体选择器；选择器遵循原版权限规则。`player` 标记玩家，`mob` 标记全部同类型生物，`group` 标记 hostile（敌对）、passive（非敌对）、players（玩家）分组。

优先级：指定玩家 > 指定生物 UUID > 生物类型 > 分组。效果参数从 0 开始：0 表示 I 级，1 表示 II 级。效果每秒刷新，普通效果解除后最多残留约 3 秒。

列表管理：`/domain ally list`、`/domain ally remove 1`、`/domain ally clear`；`enemy` 使用相同格式。清空某一类效果：`/domain effect enemy clear`。

## 常用命令

| 命令 | 用途 |
|---|---|
| `/domain` 或 `/domain info` | 查看权限、尺寸、比例、冷却和敌友列表 |
| `/domain core` | 补领核心，旧核心会失效 |
| `/domain tools` | 补领缺失工具；曾领取过后无需一直维持 50 级 |
| `/domain abandon confirm` | 永久放弃已收纳的领域及内容，之后可制作新领域 |
| `/domainexpansion bedrock 玩家名 数量` | 管理员补发基岩 |
| `/domainexpansion revoke 玩家名` | 撤销权限，保留数据并解除正在展开的领域 |
| `/domainexpansion resetcooldown 玩家名` | 清除冷却 |
| `/domainexpansion dismiss 玩家名` | 强制解除 |
| `/domainexpansion abandon 玩家名` | 删除领域，支持离线玩家 |
| `/domainexpansion info 玩家名` | 查看玩家领域信息 |

管理员命令需要原版权限等级 2。快捷键可在“选项 → 控制 → 按键绑定 → 领域展开”修改。

## 配置和边界

首次启动生成 `config/domain_expansion-common.toml`，注释已翻译为中文，可调整等级、建造限制、持续时间、消耗、吸入范围、外壳生命值、比例档位和必中开关。

外部显示为黑色长方体外壳，暂不提供 MiniScaled 那样的真实建筑微缩渲染。实体模型、碰撞箱、视线高度、移动速度、玩家交互距离会缩放；跳跃、船、矿车、投射物模型仍沿用原版行为。

必中适用于能识别领域主人为攻击者的标准伤害事件，提供近战空挥辅助和投射物追踪。伤害源没有攻击者；开启击杀掉落归属时仍按玩家击杀计算战利品。其他模组绕过标准伤害事件的攻击、闪避或免疫需要专项兼容。

异常停机后，玩家重登时返回；带返回标记的生物加载后自动返回。恢复使用保存的实际区块库存，不用旧模板覆盖库存。断电损失仍受 Minecraft 常规存档时机约束。

从原版源码升级后若核心失效，执行 `/domain core` 补领即可，原领域结构保留。

编译：`gradlew.bat build --console=plain`。独立游戏测试：`gradlew.bat runGameTestServer --console=plain`。JAR 输出到 `build/libs/`。
