# 时间线相机（Forge 1.20.1）

用相机把生物、玩家或掉落物收入照片，再把它们释放到其他地方。你也可以进入照片中的回忆，或使用照片伪装外形。回忆中的死亡、损失和破坏可能触发“时间线改写”，影响现实中的位置、生命值、饥饿值和物品。

模组 ID：`timeline_camera`。版本：`1.0.0`。客户端和服务器均须安装，使用 Minecraft 1.20.1、Forge 47.x 和 Java 17。

## 合成与拍摄

| 物品 | 合成方式 |
| --- | --- |
| 相机 | `III / IGR / III`，I 为铁锭，G 为玻璃，R 为红石粉 |
| 胶卷 ×3 | 3 张纸、1 颗末影珍珠、1 个墨囊，无序合成 |
| 照片 | 拍摄后获得 |

- 手持相机右键：捕获瞄准的生物、玩家或掉落物，默认距离 24 格。
- 潜行并右键：拍摄场景和外形快照，不带走目标。
- 每次拍摄消耗一卷胶卷，默认冷却 2 秒；创造模式不消耗胶卷。
- 末影龙、凋灵、监守者、远古守卫者以及最大生命值超过 100 的生物，默认不能被捕获。可通过配置及实体标签 `timeline_camera:unphotographable` 调整。
- 玩家生命值不高于最大生命值的一半时，才可被捕获；创造模式和旁观模式玩家不能被捕获。
- 被捕获玩家在暗房等待，默认 5 分钟后自动脱困，也可由照片持有者或管理员释放。下线与进入回忆不会重置计时。

## 使用照片

- 对方块右键：在对应位置释放照片主体。照片褪色后仍可进入回忆和伪装。
- 对空气右键：进入照片中的回忆。在回忆中再次使用照片，即可离开。
- 潜行并右键：按照片中记录的外形伪装，再次操作可解除。默认持续 60 秒，结束后冷却 30 秒。攻击实体，包括投射物造成伤害，默认会解除伪装。
- 伪装会改变模型与碰撞箱，默认最大宽 2 格、高 3 格。除非你曾伤害生物，否则生物不会主动把伪装中的你作为目标。

## 回忆与结算

默认记录主体附近 25 × 21 × 25 的场景，包含方块、容器和其他实体的回声。回忆在独立维度内重建，默认持续 5 分钟，结束后冷却 60 秒。同一张照片的副本共享主体和回忆状态；同一照片不能同时开启多段回忆。

可通过使用照片、`/camera leave`、等待倒计时或跌落离开。离开自己场景周围 64 格的范围也会结束回忆。回忆中的死亡会让你在现实中醒来，不掉落物品，生命值恢复为最大生命值的一半，并必定触发时间线改写。

默认只允许带入的物品和照片的真实主体物品离开回忆。额外取得的战利品、合成产物与经验会消散；已消耗的物品、耐久和经验等级不会退还。被捕获玩家同样结算物品和经验；若他们下线，结算会保存并在下次登录时执行。

真实主体物品可放入箱子或拆分。结束时，留在场景中的部分回到照片，带在身上的部分可以离开回忆。真实主体生物会按结束时的状态回到照片；死亡或丢失会使照片褪色。真实主体玩家回到暗房，若在回忆中死亡，则被释放。

| 行为 | 默认增加的悖论值 |
| --- | --- |
| 主体生物或玩家死亡 | 10 |
| 主体物品丢失或消耗 | 6 |
| 你在回忆中死亡 | 5，并保证触发改写 |
| 击杀回声 | 1.5；20% 概率杀死原世界中已加载的对应生物 |
| 破坏方块 | 每个 0.05，单次回忆最多增加 3 |
| 时间线改写效果尚在时进入回忆 | 2 |

悖论值不低于 1 时，随机改写概率为悖论值 × 10%，最高 100%。低于 5 为轻微，5 至不足 10 为严重，10 及以上为剧烈。改写效果默认持续 5 分钟。

| 影响 | 轻微 | 严重 | 剧烈 |
| --- | --- | --- | --- |
| 返回位置偏移上限 | 6 格 | 20 格 | 48 格 |
| 生命值变化上限 | ±1 颗心 | ±2 颗心 | ±4 颗心 |
| 饥饿值变化上限 | ±2 | ±4 | ±8 |
| 数量或耐久变化的物品堆数 | 1 | 2 | 4 |
| 随机替换为场景中一种物品 | 无 | 无 | 1 堆 |

改写不会直接把生命值降低至零；物品数量可能增加，也可能减少。

## 命令

| 命令 | 权限 | 用途 |
| --- | --- | --- |
| `/camera leave` | 所有人 | 离开自己的回忆 |
| `/camera undisguise` | 所有人 | 解除伪装 |
| `/camera status` | 所有人 | 查看回忆、暗房、伪装与冷却状态 |
| `/camera free <players>` | 管理员 | 在捕获位置释放被困玩家 |
| `/camera endmemory <players>` | 管理员 | 结束玩家的回忆 |

## 配置与存储

`config/timeline_camera-common.toml` 控制拍摄距离、胶卷、捕获限制、玩家暗房时间、场景范围、回声数量、回忆时长、悖论、时间线改写及伪装。`config/timeline_camera-client.toml` 控制回忆滤镜和 HUD。配置项 ID 保留英文以兼容已有配置，说明注释为中文。

照片保存在 `<存档>/data/timeline_camera/photos/<UUID>.dat`。照片物品只包含 ID 和显示信息，复制照片不会复制真实主体。照片缓存最多保留 64 条记录，并按 NBT 估算占用控制在 64 MiB 内；淘汰缓存不会删除照片文件。照片以临时文件替换方式保存，保存失败会中止捕获、释放或回忆结算。

进行中的回忆及离线待结算状态保存在 `timeline_camera_memories.dat`，被捕获玩家保存在 `timeline_camera_traps.dat`。普通退出与重启后可以继续处理；强制终止进程时，照片文件和世界存档之间仍存在无法完全消除的保存时序窗口。

## 已知范围与限制

- 回忆的时间与天气由客户端展示，服务器使用该维度的统一时间与天气；多张不同时间的照片无法同时改变同一服务器维度的环境规则。
- 下界和末地的回忆仍使用主世界式天空。
- 伪装不完整模拟实体的特殊动画；第三方实体渲染失败时回退为玩家模型，并保留服务端碰撞箱。
- 本模组自有界面与提示、原版维度名、回忆维度名、模组说明及配置注释均有中文。第三方生物、群系与维度名称依赖对应模组或资源包的翻译；无维度译名时显示其注册 ID。
- 回忆禁止末影箱、跨维度传送和进入其他场地。管理员应通过 `/camera endmemory` 结束访问。
- 第三方跨维度背包、远程存储或其他绕过原版背包的系统，需要在具体整合包中额外验证。
